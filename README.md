# 🚄 高鐵車票報帳小幫手

把台灣高鐵車票整理成報帳資料的純前端網頁：

**車票截圖／照片 → OCR 明細 → 電子車票證明 PDF 自動解密合併 → 套用 Word 模板產生報帳單**

👉 線上使用：<https://renhuang-huang.github.io/thsrc-expense-report/>

🔒 **隱私**：所有圖片、PDF、Word 模板都只在你的瀏覽器裡處理，沒有後端伺服器，也不會上傳任何檔案。
唯一例外：你選擇用「Claude」辨識並自行填入 API key 時，圖片會直接從你的瀏覽器送到 Anthropic API（不經過本站）。API key 只存在該分頁（sessionStorage），關閉分頁就清除。

## 使用者只要做三件事

1. **上傳車票照片**（T Express 截圖、紙本車票照片都可以）
2. **（選）上傳 Word 模板**，沒有就用內建範例
3. **補齊紅框欄位**

其他都由系統完成：OCR 辨識 → 自動到高鐵網站下載電子車票證明 → 用搭乘日期解密 → 從證明讀出票價 → 合併成無密碼 PDF → 套用 Word 模板。

## 功能

| 區塊 | 說明 |
|---|---|
| 報帳資料 | 申請人、申請日期（預設今天 `yyyy/mm/dd`）、出差描述、統一編號（選填）、公司名稱（選填）。除了申請日期，都會存在這台電腦的瀏覽器（localStorage），下次自動帶入。 |
| 車票明細 | OCR 解析出：類型（手機／紙本）、座別（對號座／自由座）、搭乘日期、起訖站、車票號碼 13 碼、訂位代號 8 碼。紙本照片旋轉 90 度也能辨識。缺漏的欄位標紅，可直接修改、新增、刪除。 |
| 金額 | 不需要手填：截圖通常沒有票價，系統會從下載回來的電子車票證明讀出票價。 |
| 電子車票證明 | 安裝一次「自動下載」擴充功能後，按一個按鈕就會自動到高鐵 ptis 網站逐張查詢下載（手機票會順便填好統編與公司名稱），PDF 直接傳回網頁解密、對應明細。 |
| 匯出 | **合併 PDF**（依日期排序、無密碼，可在最前面加一頁報帳單）、**Word 報帳單**、**明細 CSV**、**報帳單 PDF**。 |
| 外觀 | 右上角可切換淺色／深色，會記住你的選擇。手機版有卡片式明細與底部總金額列。 |

### 自動下載擴充功能

高鐵網站有 reCAPTCHA、不允許其他網站呼叫，而且每張證明只能下載一次，一般網頁沒辦法代為下載，所以需要裝一個 Chrome／Edge 擴充功能（電腦版）。它在你自己的瀏覽器裡開一個高鐵網站視窗，照原本 Python 工具驗證過的步驟自動填表、下載，完成後自動關閉視窗。

- **安裝**：網頁上按「下載擴充功能」→ 解壓縮 → `chrome://extensions` 打開「開發人員模式」→「載入未封裝項目」選 `thsrc-helper-extension` 資料夾 → 重新整理網頁。原始碼在 [`extension/`](extension/)。
- **權限**：只能存取 `ptis.thsrc.com.tw`，以及本站的網頁。下載期間 Chrome 上方會出現「正在偵錯這個瀏覽器」的提示，這是擴充功能用來取得 PDF 內容的方式（Chrome 也會照常存一份到下載資料夾），下載完就會解除。
- **各種結果**：成功 → 自動解密、帶入票價；「資料被拒」→ 高鐵說資料不對，修改後可再按一次；「已被下載過」→ 之前已經下載過，請把下載資料夾裡的檔案拖到「手動下載與上傳」。
- 手機或沒辦法裝擴充功能時，可展開「手動下載與上傳」，照每筆的查詢資料自己下載，再把 PDF 拖回網頁（一樣自動解密、對應、帶入票價）。

### OCR 引擎

- **本機辨識**（預設、免費）：Tesseract.js（`chi_tra` + `eng`）在瀏覽器裡辨識，第一次會載入約 8MB 的引擎與語言資料，都放在本站。
- **Claude API**（選用，較準）：填入你自己的 Anthropic API key，瀏覽器直接呼叫 Messages API（模型 `claude-sonnet-5-5`）。key 只存在該分頁。

## Word 模板佔位符

佔位符一律寫成 `{{名稱}}`：

| 佔位符 | 內容 |
|---|---|
| `{{申請人}}` | 使用者填的申請人 |
| `{{申請日期}}` | 預設今天，格式 `yyyy/mm/dd` |
| `{{出差描述}}` | 使用者填的出差描述 |
| `{{統一編號}}` | 選填，沒填就是空白 |
| `{{公司名稱}}` | 選填，沒填就是空白 |
| `{{總金額}}` | 所有車票金額加總，有千分位（例：`1,560`） |
| `{{筆數}}` | 車票張數 |
| `{{清單}}` | 多行文字，每行 `日期,起站,迄站,金額`，依日期排序 |
| `{{#清單}}…{{/清單}}` | 每筆重複一次。區塊內可用 `{{序號}}` `{{日期}}` `{{起站}}` `{{迄站}}` `{{金額}}` `{{車票號碼}}` `{{訂位代號}}` |

**表格逐列展開**：在表格的某一列，第一格開頭寫 `{{#清單}}{{序號}}`、中間格寫 `{{日期}}` `{{起站}}` `{{迄站}}`、最後一格寫 `{{金額}}{{/清單}}`，匯出時這一列會依車票數量自動複製。可以參考網頁上的「下載範例模板」（[`public/sample-template.docx`](public/sample-template.docx)）。

> 小提醒：在 Word 裡打佔位符時，盡量一次打完、不要中途改格式，`{{` 和 `}}` 請用半形。

## 使用步驟

1. 填申請人、出差描述（需要的話填統編與公司名稱），下次會自動帶入。
2. 上傳這次要報帳的所有車票截圖／照片，等辨識完成。
3. 把紅框補好。**一定要確認正確**，因為每張電子車票證明只能下載一次。
4. 按「自動下載 N 張證明」，等它跑完（會跳出高鐵網站視窗，完成後自動關閉）。
5. （選）上傳自己的 Word 模板。
6. 按「合併 PDF」「Word 報帳單」匯出。

## 限制

- 自動下載需要電腦版 Chrome／Edge 加上擴充功能。若高鐵網站改版，擴充功能裡的欄位位置（`extension/background.js`）可能要跟著調整。
- reCAPTCHA v3 是看行為給分數，若查詢一直送不出去，請在跳出的高鐵視窗手動按一次「開始查詢」後再試。
- 電子車票證明的開啟密碼是搭乘日期 `YYYYMMDD`。網頁會先用 [qpdf](https://github.com/qpdf/qpdf)（WASM）解密再用 pdf-lib 合併；萬一解不開，會改用 pdf.js 以密碼開啟後把每頁轉成高解析影像重建（此時合併檔裡的文字無法選取）。
- OCR 不保證百分之百正確，尤其是 Tesseract.js。請在下載證明前人工核對。
- 報帳單封面用瀏覽器內建字型繪製成影像，字型外觀會依作業系統略有不同。
- 本工具與台灣高鐵公司無關。

## 開發

需要 Node.js 22 以上。

```bash
npm install
npm run dev      # 本機開發 http://localhost:5173/thsrc-expense-report/
npm test         # 單元測試（OCR 文字解析、日期格式、金額加總、Word 模板、PDF 解密合併）
npm run build    # 產出 dist/
npm run make-template   # 重新產生 public/sample-template.docx
```

`npm run dev` / `npm run build` 會先執行 `scripts/copy-vendor.mjs`，把 Tesseract 引擎、中文語言資料與 pdf.js 字型表從 `node_modules` 複製到 `public/vendor/`（不進版控），並把 `extension/` 打包成 `public/thsrc-helper-extension.zip` 供網頁下載。

技術：Vite + TypeScript（無框架）、tesseract.js、pdf.js、pdf-lib、qpdf-wasm、docxtemplater + PizZip、@anthropic-ai/sdk。

### 程式結構

| 檔案 | 用途 |
|---|---|
| `src/parse.ts` | OCR 文字與證明 PDF 內文的解析規則 |
| `src/stations.ts` | 站名正規化與代碼（南港 1 … 左營 12，台／臺都接受） |
| `src/format.ts` | 日期格式、金額加總、CSV、缺漏欄位檢查 |
| `src/ocr.ts` | Tesseract.js（含自動旋轉重試）與 Claude 辨識 |
| `src/pdf.ts` / `src/pdfjs.ts` | qpdf 解密、pdf-lib 合併、pdf.js 讀內文與影像備援 |
| `src/template.ts` | 套用 Word 模板 |
| `src/cover.ts` | 報帳單 PDF 頁面 |
| `src/main.ts` | 畫面與流程 |
